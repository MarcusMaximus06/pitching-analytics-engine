# Premium Pitcher Matchup Cards Plan

## Goal
Make the MLB manual simulator feel more premium and Baseball Savant-inspired without changing model logic.

## First Version
Add side-by-side pitcher cards showing:
- pitcher name
- team
- FIP
- recent ERA
- innings pitched
- strikeouts
- K/9
- form label

## Visual Style
- clean card layout
- side-by-side columns
- compact stat grid
- form badge: Hot / Stable / Cold
- no model math changes

## Future Enhancements
- percentile bars
- radar charts
- rolling ERA trend
- pitcher comparison chart
- Statcast-style profile view
