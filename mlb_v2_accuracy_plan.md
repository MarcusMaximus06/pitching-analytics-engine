# MLB V2 Accuracy Dashboard Plan

## Goal
Measure whether MLB Model V2 is improving prediction quality.

## Track
- Total graded games
- Overall model accuracy
- Vegas favorite accuracy
- High confidence accuracy
- Medium confidence accuracy
- Low confidence accuracy
- Underdog pick accuracy

## Why This Matters
The model should not just make picks.
It should prove which types of picks are profitable or accurate over time.

## First Dashboard Version
Read from MLB Log V2 and display:
- total pending
- total graded
- win/loss count
- accuracy by confidence tier

## Later Additions
- ROI tracking
- closing line value
- edge size buckets
- underdog/favorite split
- pitcher-form impact
- recent-form impact
