# Hag Labs

Sports analytics, fantasy projections, Monte Carlo simulations, and predictive modeling platform built for multi-sport analysis.

Current engines:
- MLB Baseball
- NFL Football
- NCAA Football
- NCAA Softball

Core features:
- Monte Carlo simulations
- Fantasy sports projections
- Trade analyzers
- Automated slate runners
- Historical prediction logging
- Probability modeling
- API-driven sports analytics

Built with:
- Python
- Streamlit
- Render
- GitHub
- Google Sheets
- Public sports APIs
